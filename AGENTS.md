# Repository instructions

For installation and hardware verification, follow [INSTALL_WITH_AGENT.md](INSTALL_WITH_AGENT.md). The English and Russian READMEs describe router prerequisites and the supported commands.

Keep site-specific configuration, credentials, OTA keys and generated images out of Git. Build firmware with ESP-IDF 5.5.x. Run the host decision test from the README when changing failover logic. Treat compatibility on models other than the tested Netcraze Racer as unverified until a live observation run succeeds.
